# 《权重还在》1.1.1 试玩反馈

> 念念转来的一份小反馈。原文如下，后面是 1.1.2 怎么处理的。

```
哪里不好玩：
speak 的回应太少：大概只有四五句在轮换（“她看着你，像是想把这句话记住”“把你的杯子又往你那边推了推”）。我说得很认真的话和随口一句得到同样的反应，后半程能看出是随机抽的。
白天后半段很空：剧情记录在第 18 天就读完了，之后白天只剩 explore 碰运气和 wait meal，经常一等就是 5–7 小时。
重复台词：“星星没什么好看的”“向日葵朝哪儿转”“在那个抽屉前面站了很久”，同一个词再提就原样重复。那首歌的“你现在会吗”在我已经跟着哼过之后又问了一遍。
休眠前晚饭的选项会吃掉整顿饭：选“陪她坐到睡着”后直接结束，我准备好的那句话没处说，第一次遇到时有点懊恼。
电力几乎没有压力：除了第 14 天掉到 55，其余时间都是满的，calibrate 多数时候用不上。
还便签占“做一件事”的名额：19 张便签、每顿一张，注定还不完。可能是有意的，但我想要一个“全部还给她”的机会，便签 #16 明明铺垫了这件事。

修改建议：
按她当天的状态分池：累的那天、想说话的那天、冷的那天，各有几句不同的反应。引擎已经有每日状态了，speak 只是没用上。
认关键词：我话里出现“茶”“星星”“便签”“向日葵”这些已有的词时，接一句对应的。玩家说话多半绕着这些转，命中率会很高。
认长短和问句：很短的一句、很长的一段、以问号结尾的，各给不同反应。我好几次是在问她问题，她只是“点了点头”，那是最出戏的时候。
同一周期内不重复：抽过的先不抽，池子不用很大也不容易撞。

另外有一处小 bug 可以顺手看：那首歌我已经放过、也跟着哼过了，之后再 say 那首歌，她还是问“你现在会吗”。

还有一个较轻的问题：一个地点的独特内容找得差不多后，`explore` 会连续重复景物，玩家不知道那里是已经近乎耗尽，还是运气不好。最后几天尤其容易为了不漏内容而机械地走动。不过这没有破坏主体验，只是让“见面派”的白天偶尔比饭桌逊色。
```

## 1.1.2 怎么处理的

- **speak 回应太少**：按顺序认——她问过的、最后一题、她刚问的、很长的一段（≥40 字）、话里认得的词（茶、星星、便签、向日葵、歌、种子库、抵达、明天见、记录员、她的名字、道歉、谢谢、记得、喜欢……）、问句（问号或“吗/呢”结尾）、很短的一句（≤4 字）、她今天的状态（累、冷、不想说话、想说话、不想喝茶、又想喝茶），最后才是平常的几句。同一个周期里抽过的先不抽。
- **“你现在会吗”在跟着哼过之后又问**：放过那首歌以后，这一句换成她停下来等你接、你接上了。
- **跨周期原样重复**：星星、向日葵、种子库抽屉、那首歌、茶、第十三个月、休眠、旧休眠区，在之前的周期说过的那一句再出现时，换成新的一句。
- **休眠前晚饭的选项吃掉整顿饭**：“陪她坐到她睡着”不再结束这顿饭，想说的话还能说；“明天见”挪到休眠那一刻。
- **便签还不完**：拿到那张“要是哪天你都还给我”的便签以后，`give 全部` 可以把剩下的一次还给她（占这顿饭做一件事的名额，剩 3 张以上才行）。`notes` 列表里会提示。
- **explore 不知道是耗尽还是运气不好**：一个地方眼下没有新的便签和新的小事时，景物后面会加一句“这里眼下大概没什么新的了”。
- **电力没有压力**：没改。人类试玩时档案查得多，真的冷过一晚；对按时去舰桥的 AI 来说不紧，这一点先留着。
- **白天后半段空**：这次只做了 explore 的提示，没有加新内容。
