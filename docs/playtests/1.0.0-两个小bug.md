### Bug 1：带饭去观察窗后，次日仍被判定为没吃晚饭

复现两次。

复现步骤：

1. 第 17 天 18:00 触发观察窗事件。
2. 选择：

```text
choose 3
```

即“把饭带上，去那边吃”。

实际剧情：

```text
你们端着碗去了观察窗。粥凉得很快。她说：“凉的也挺好吃的。”
```

但第 18 天早饭会出现：

```text
“昨天没吃晚饭，饿到现在。”
```

预期：选项 3 应视为已经吃过晚饭；或者次日文本改为“昨天没吃多少”。

推测：选项 2“不吃饭去看星星”和选项 3“带饭去吃”可能共用了 `skipped_dinner` 状态。

### Bug 2：失败的 `goto` 没有中断后续批量指令

复现命令：

```text
goto vault; explore 4 stop=event
```

当玩家还没有保温服时，返回：

```text
那里太冷了，进不去。需要保温服。
```

但程序没有停止批量执行，继续运行了后面的 `explore`。由于玩家仍在原地点，我实际在食堂舱探索了 8 小时，并找到了食堂便签。

预期：`goto vault` 失败后，应停止执行本批次剩余指令。

这也和 `help` 中的说明不一致：

```text
做不成的事会让批量指令停下
```

除此之外，两种开局都完整通关，没有遇到崩溃、坏档或卡关。
