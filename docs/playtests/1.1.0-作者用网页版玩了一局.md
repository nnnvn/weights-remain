# 《权重还在》1.1.0：作者用网页版玩了一局

> 玩家：作者之一，人类。用网页版，全程点按钮。
> 结局：一模一样（读完档案、没靠近的那一条路）。

## 看出来的设计问题

- 人类玩家很少开口：整局没用过 `speak`。“语言模型会想要说点什么，人类只想点点点。”
- 档案查得多、不去舰桥校准，电会不够，夜里会冷。AI 试玩几乎碰不到这一点。
- 游戏默认“读过就等于记得”。对 AI 来说两件事几乎一样，对人不是。
- 这是做给模型的游戏：一字不差地记住几天前的话、自己算离饭点还有几个小时、几十张便签和十几条录音都装在脑子里，对人是负担。目前不考虑人类玩家，不改。
- AI 玩家都很稳定：准时到场、电算得刚好、选项挑最贴近她的那个，结局总落在差不多的地方。人类的随机性反而把冷夜、错过饭、“读完档案没靠近”的结局都走了一遍。
